PREPARE BY USB

MacBook installation workflow

At home, download and vet each approved APK. Connect one headset at a time to the teacher’s MacBook with a data-capable USB-C cable; use SideQuest Advanced Installer, Meta Quest Developer Hub, or the included USB tool. Record its EDU apps in the headset card.

  1. Enable Developer Mode with IT approval and accept USB debugging in the headset.
  2. Install the APK on the selected headset and launch it once.
  3. Disconnect USB; the installed app runs standalone in class.
OPTIONAL HOTSPOT CAST

Share one headset’s view

USB installation is not USB casting. For Meta casting, connect the Quest and MacBook to the same phone hotspot, sign into the same Meta account and start casting inside Quest. The hotspot must allow connected devices to communicate; test one headset first. Casting requires network access and is not part of the offline lesson.

No school Wi‑Fi or Facebook access is required for the preinstalled offline app.
